# Trading Journal

A personal options trading journal to help track trades, reflect on performance, and build better habits over time.

## Features

- **Trading Calendar** — visualize win/loss days and weekly P&L at a glance
- **Log a Trade** — record entry/exit, setup type, emotions, and trade grade
- **Trade History** — view, edit, and delete past trades with export/import support
- **Statistics** — break down performance by grade, setup, emotion, and rules followed

## Tech Stack

- HTML, CSS, JavaScript (vanilla)
- localStorage for data persistence
- No frameworks, no dependencies

## Getting Started

Just open `index.html` in your browser — no setup or installation needed.
